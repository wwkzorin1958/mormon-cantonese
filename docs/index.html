在很久以前，我有一個心願，希望能錄製廣東話版的摩爾門經，帶給有需要的人聆聽。

用 Podcast 應用收聽（iPhone 及 Android）

複製以下網址，貼到你的 Podcast 應用：

https://wwkzorin1958.github.io/mormon-cantonese/feed.xml

  1. Apple Podcasts：資料庫 → 右上角 ⋯ → 「依 URL 加入節目」
  2. AntennaPod（Android）：新增 Podcast → 貼上網址
  3. 其他應用：尋找「加入 Podcast / Add by URL」

加入後可下載全部集數，離線收聽，鎖屏亦可播放。
